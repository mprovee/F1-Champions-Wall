# F1-Champions-Wall
Clickable grid display of all Formula 1 Champions.
This file relies on tkinter for the GUI and PIL for images and image formatting
The application displays a 6x6 grid of "portraits" of every F1 Champion in history. Each champion has a photo, and upon being clicked, a profile including the years and teams they were champions with as well as a short bio to educate users on their histories.
